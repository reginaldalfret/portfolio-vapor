### 1. Executive Summary

This repository is one of **twelve independent native technology implementations** of the personal portfolio of Reginald Alfret V. 

The core concept is:

**12 STACKS. 1 PRODUCT.**

Rather than rendering static HTML replicas or shared client templates, this repository is built genuinely within the **Vapor 4** ecosystem, utilizing Swift 6.0 / 5.10 and native framework conventions (Leaf Dynamic Server-Side Template Engine).

### 4. Prerequisites & Local Development

#### Prerequisites
- Swift 5.10+ / Swift 6.0 Toolchain

#### Installation
```bash
git clone https://github.com/reginaldalfret/portfolio-vapor.git
cd Portfolio-Vapor
swift package resolve
```

#### Running Development Server
```bash
swift run App
```

#### Production Build
```bash
swift build -c release
```

#### Running Test Suite
```bash
swift test
```
