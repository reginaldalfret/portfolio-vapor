# Reginald Alfret V - Portfolio (Vapor 4 / Swift)

> Modern obsidian dark liquid-glass engineering resume portfolio built with **Vapor 4**, **Swift 5.10 / 6.0**, and **Tailwind CSS**.

## 💧 Architecture & Technology Stack
- **Framework:** Vapor 4 (`vapor/vapor` 4.99+)
- **Runtime:** Swift 5.10+ with Non-blocking SwiftNIO Async I/O
- **Templating:** Leaf (`vapor/leaf`) / Dynamic SSR HTML
- **Styling:** Obsidian Dark Liquid-Glass Theme with Aqua / Sky Blue accents (`#0284c7`, `#38bdf8`)
- **Port:** `8093`
- **Features:**
  - 30 Merged PRs across Apple, Google, Microsoft, Meta, AWS, NVIDIA, etc. with category filtering.
  - Work experiences, featured AI/ML engineering projects, achievements, and certifications.
  - Dual-mode interactive resume switcher (Interactive Resume vs Original PDF Viewer).
  - 12-Stack Floating Command Dock (`Next.js`, `Nuxt 3`, `Django`, `Spring Boot`, `Laravel`, `Rails`, `Angular`, `Blazor`, `Buffalo`, `Leptos`, `Jaspr`, `Vapor`).
  - Instant iframe detection & dock suppression for container integration.

## 🚀 Running Locally
```bash
# Using Swift Package Manager
swift run

# Or using the local daemon
python serve.py
```
App runs at `http://127.0.0.1:8093`.
